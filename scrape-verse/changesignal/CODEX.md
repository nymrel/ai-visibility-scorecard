# Agent boundary

Work in this directory only unless a repository owner explicitly expands scope.

Allowed without additional approval:

- read source and fixtures;
- run `npm test` and `npm run demo`;
- improve deterministic tests, normalization, reports, and documentation;
- use mocked/injected HTTP responses.

Retained approvals:

- event registration and legal terms;
- Bright Data account, token, collector creation, and live API use;
- any paid plan or unexpected usage charge;
- target selection and collection-rights review;
- public deployment, video publication, repository visibility changes, final submission, and publicity.

Never commit credentials or claim a live Bright Data run from fixture-only evidence.
